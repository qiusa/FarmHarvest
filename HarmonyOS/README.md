# 事项提醒 · HarmonyOS 元服务

此工程位于独立目录，不影响现有 macOS / iOS Xcode 工程。实现以 `FarmHarvestiOS/PhoneContentView.swift` 和 `FarmHarvest/CropStore.swift` 为功能基准，使用 ArkTS / ArkUI 原生页面。

## 已实现

- **新建事项**：内置模板、自定义模板、分钟间隔、备注、预计提醒时间。
- **事项记录**：待提醒 / 已到期 / 总计统计；逐秒倒计时；逐次标记完成或撤销；再次提醒；编辑名称、备注、单次提醒时间与完成状态；从现在起调整；追加和删除提醒；删除记录；清理已结束记录。
- **数据备份**：兼容 iOS 的版本 1 JSON 备份字段；远程上传、远程合并 / 替换、本地 JSON 导入 / 导出；保存最近上传时间。
- **运行中提示**：元服务页面运行时检查每次未完成提醒，到期前两分钟及到期时显示短暂前台提示；重新打开后检查已到期提醒。
- **本机持久化**：状态保存在元服务沙箱；备份与 iOS 使用相同的 JSON 字段，可通过数据页进行设备间迁移。

## 使用

1. 使用支持 HarmonyOS 6.1.1 / API 24 的 DevEco Studio 打开本目录。
2. 在 AppGallery Connect 创建/关联元服务后，将 `AppScope/app.json5` 中的 `bundleName` 替换为控制台分配的元服务包名；当前值 `com.atomicservice.farmharvest` 仅作工程占位。
3. 配置开发者签名并在真机运行。当前构建配置未包含签名，Hvigor 会生成未签名 HAP；上架或安装前需完成签名配置。

**与 iOS 的功能差异**：iOS 可在应用退出后通过系统通知中心按时提醒；当前 HarmonyOS 元服务 API 集不允许发布系统通知或使用 ReminderAgent 定时提醒。因此此元服务只在页面运行时显示前台提示，退出后无法保证提醒，也不会请求系统通知权限。若必须达到 iOS 的后台提醒能力，需要将此功能改为常规 HarmonyOS 应用，或等待元服务开放对应 API。

数据页保留 iOS 使用的共享目录地址和上传接口。上传凭据沿用现有 iOS 客户端配置；该接口为 HTTP 局域网服务，请只在可信网络使用。备份内容不做云端自动同步。
