
## Android 分支移植自动同步（codex/android-apk-parity）

- 对应 main 的脏标记合并语义落到 Kotlin：`FarmData.kt` 增加 `SyncChangeState`/`SyncBackup` 与纯函数 `initialSyncState/changedRecordIDs/trackedRecordSave/clearedSyncChanges`；`saveRecords` 改 commit 并按 diff 记脏（所有记录改动的唯一入口），`writeCustomCrops/writeHiddenBuiltins` 同理；`importBackup` 改走记脏写入；`applySyncedData` 不记脏 + 通知；监听器用 CopyOnWriteArrayList（JVM 可测、无 Android 广播依赖）。
- `AutoSync.kt`：主线程 Handler debounce（改动2s/回前台1s/定时300s）+ 单线程 executor 串行 syncOnce；合并/同内容判定为顶层纯函数供 JVM 测试。`BackupApi.fetchBackup` 区分 404(NotFound)/失败(Failed)/成功，LAN 10s、公网 30s 超时。
- `MainActivity`：onCreate 挂 synced 监听→runOnUiThread reload + AutoSync.start；onResume→onForeground；onDestroy 摘监听。
- 验证：JVM 18/18（新增 AutoSyncMergeTest 14 条）；`build-apk.sh` 全流水线（test+lint+assembleDebug+assembleRelease）成功，dist APK 产出（dist/ 被 gitignore）。
- **Android 真端到端配方（headless 模拟器 + adb）**：已有 AVD guoxin35（android-35）→ `emulator -avd guoxin35 -no-window -gpu swiftshader_indirect` → `adb install -r` → `am start` → `adb shell run-as <pkg> cat shared_prefs/farm-harvest.xml` 读真实落盘（debug 包可 run-as）→ `uiautomator dump` + `input tap` 实点（Compose 的 content-desc「编辑」「保存」可定位；中文输入不行，标记用 ASCII）→ 服务器 exportedAt 对账。
- **坑1：AVD 里残留旧应用数据 = 首启脏全标回灌事故。** install -r 保留数据；旧数据首启被全标脏推上服务器，顶掉 Mac 较新版本（本次 4 条 note/minutes/harvests 回灌）。E2E 前必须 `pm clear <pkg>` 模拟全新安装。恢复手法：基线快照 + 保留事故窗口内他端真实编辑（本次 Mac 的「好了」收获）构造 recovery payload 回灌；Mac/Android 随后各自同步自愈。
- **坑2：`am start` 对已置顶实例不触发 onResume**（"intent delivered to currently running top-most instance"），回前台同步不会跑；要先 `input keyevent 3`(HOME) 再 am start 才制造真实 resume。
- **坑3：LAN 不可达时是 10s connect 超时拖慢整轮同步**（curl 侧是立即 empty reply，模拟器 NAT 侧表现为 hang），对账 curl 要等 ≥15s，别在 4s 时误判「没上传」。
- 坑4：gradle 需要 ANDROID_HOME（build-apk.sh 自己 export；裸 ./gradlew 不会），且 `cmd | tail` 会掩盖 gradle 退出码，判成败看日志 BUILD SUCCESSFUL 或单独 echo EXIT。
