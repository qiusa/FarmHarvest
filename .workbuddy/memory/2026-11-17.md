## iOS 真机打包安装（Release）与首启同步对账

- 流程：`xcodebuild -scheme FarmHarvestiOS -configuration Release -destination 'platform=iOS,id=00008110-00121CEA0E51801E' -derivedDataPath build/DerivedData-ios-device -allowProvisioningUpdates build` → `devicectl device install app` → `devicectl device process launch --terminate-existing`（手机需解锁且 available (paired)；昨日曾 unavailable/error 4016，连接状态随插拔/解锁波动）。
- 对账基线要先取**即时**快照：本次安装前快照 exportedAt=01:32:38Z，但启动后服务器是 01:37:40Z——差值发生在启动**之前**（Mac 侧用户收获星沙），不是手机推的。判据：服务器 exportedAt 早于 launch 时刻 ⇒ 该变更与本次启动无关；启动后 exportedAt 不变 ⇒ 新包首启**没有**覆盖服务器（首启信任本地的脏全标设计未造成旧数据回灌）。
- **How to apply:** 真机首启对账时别拿几十分钟前的快照当基线就喊 REGRESSION；先比 exportedAt 与 launch 时刻的先后，再比内容。回灌脚本 `/tmp/fh-restore-wan.sh`（令牌运行时从 SourceFileUploader.swift 读取，脚本不含明文）：multipart 字段 `file`、filename=FarmHarvest.json、头 `x-upload-token`，期望 201。
- 版本号不 bump（恒 1.0(1)），`devicectl device info apps` 无法区分新旧包；安装成功判据看 install 命令 exit 0 + 成功 dump 字段（installationURL/databaseUUID…），启动看 launch 返回 pid/确认文案。
