## 自动同步：脏标记合并（改动上传 + 未改动跟随服务器最新）

- 需求原话：「每次修改数据都会同步到服务器，并保持其它没改的数据变成最新」。实现为 pull-merge-push，不是盲覆盖。
- 结构：`FarmHarvest/CropStore.swift` 增加 `SyncChangeState`（revision + dirtyRecordIDs 含删除墓碑 + customCropsDirty/hiddenBuiltinsDirty），落盘 `storageRoot/sync-state.json`；save/saveCustom/saveHiddenBuiltinIDs 只在写盘成功后按 diff 记脏，内容不变不 bump revision。`FarmHarvest/AutoSync.swift`（新文件，**只进 Mac+iOS target，不进 Widget**）actor Engine：2s 改动 debounce / 1s 回前台 / 300s 定时；合并基 = 两通道可达备份里 exportedAt 最新者；脏 ID 用本地、非脏用服务器（服务器没有=别处删了，跟随）；双 404 用本地重seed、双不可达直接放弃（绝不因拉取失败删本地）。revision 守卫防同步中途编辑。
- 首启初始化把现有本地数据全标脏，避免第一次同步抹掉本地；空本地首启则纯拉取（iOS 模拟器实测）。
- UI 回刷坑：拉取写盘后窗口 `@State records` 不会自己更新（didBecomeActive 的重载早于同步完成）。新增 `CropStore.syncedDataDidChangeNotification`，ContentView / PhoneContentView / CropManagerSheet 三处 onReceive 重载。实测服务器改备注后切前台界面_live_更新。
- 验证（真端到端）：受控 UI 编辑星沙备注加标记 → 服务器 11:22:54Z 自动上传，**仅该条 note 变化，其余 4 条与 customCrops/hiddenBuiltins 逐字节不变**；UI 还原 → 11:24:26Z 上传后与编辑前快照完全一致。iOS 模拟器冷启动 → 拉取 5 条+模板+隐藏列表落盘、脏标记清空、服务器 exportedAt 不变（无误推）。离线合并测试 24/24（/tmp/fh-autosync-test）。

## macOS UI 自动化：什么能用、什么不能用（实测结论）

- **能用**：System Events keystroke / key code（含 Cmd+A、Cmd+V、Tab）；对 SwiftUI 按钮 `perform action "AXPress"`（铅笔编辑、保存都靠它）；`set elems to entire contents of window 1` 物化后按索引取元素读 position/value。
- **不能用**：坐标点击（System Events `click at` 与自编译 CGEvent 二进制都送不达，TCC）；`keystroke` 中文（被拼音输入法转成乱码字母）——中文一律剪贴板+Cmd+V；`item N of (entire contents of window 1)` 不物化直接取会 -1700；按钮的 title/name/description 全是 missing value，footer 取消/保存靠「size 64x24 里 x 最大者=保存」区分。
- 读焦点：`value of attribute "AXFocusedUIElement" of process ...`（`focused UI element` 语法报错）。编辑弹窗打开时焦点默认在名称框，Tab 一次到备注 TextEditor。
- 每秒倒计时重渲染会让「边遍历边读 position/help」的循环失稳；先单遍只读 class+value 收集、再按索引二次访问才稳。
- `screencapture -x` 现在**可用**（10-23 时还没屏幕录制权限），像素级核对恢复可行。

## iOS 无真机时的模拟器验证配方（headless）

- 本机无 Simulator.app（Xcode 精简版），但 iOS 27.0 runtime 在、`simctl` 可 headless boot；devicectl 里 headless 模拟器显示 connected，真机 availability 随连接状态波动（本次 iPhone 13 Pro Max unavailable，error 4016）。
- 配方：`xcodebuild -scheme FarmHarvestiOS -destination 'platform=iOS Simulator,name=iPhone 18 Pro' -derivedDataPath build/DerivedDataSim build` → `simctl install <UDID> <app>` → `simctl launch <UDID> com.yixin.farmharvest.ios` → 读 `~/Library/Developer/CoreSimulator/Devices/<UDID>/data/Containers/Data/Application/*/Library/Application Support/FarmHarvest/` 下 records.json/sync-state.json 对账 → `simctl io <UDID> screenshot` 看像素。

- iOS target 无 entitlements（10-23 已记录）→ 模拟器与真机都走 Application Support 私有回退，属设计内，同步不受影响。
